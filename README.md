This project is a dynamic responsive portfolio webpage that was put together using Node.js, ExpressJS and the Embedded Javascript templating engine. It incorporates Bootstrap 5, font awesome 6 and custom css3 properties.

Cloud provider: https://assignment-2-odcw.onrender.com/
GitHub repository: https://github.com/EMMY2005TECH/Assignment-2
